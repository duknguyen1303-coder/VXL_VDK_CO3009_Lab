# Lab 1: LED Animations

## Exercise 1
2 LED (RED - PA5, YELLOW - PA6) đổi trạng thái luân phiên mỗi 2 giây.

## Exercise 2
Thêm LED-GREEN (PA7), mô phỏng đèn giao thông:
- RED: 5s
- YELLOW: 2s
- GREEN: 3s

## Exercise 3
Mở rộng thành đèn giao thông 4 hướng (12 LED).

## Exercise 4
Thêm 1 LED 7 đoạn (7SEG-COM-ANODE, nối PB0-PB6).
Viết hàm display7SEG(int num) hiển thị số 0-9.
